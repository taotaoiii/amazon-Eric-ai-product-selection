# 数据源与双模式对照

> 全文不出现具体业务阈值，一律引用 `config/anchors.yaml`。

## 一、口径优先级（不可颠倒）

**官方数据 > 第三方估算 > 站外信号**

| 级别 | 来源 | 用法 |
|---|---|---|
| 官方 | 亚马逊商机探测器、Revenue Calculator、ABA | 直接采信 |
| 第三方估算 | Sorftime、卖家精灵、Helium 10、Keepa | **只用于排序和交叉验证**，误差通常很大 |
| 站外 | Google Trends、TikTok、Pinterest、Reddit | **仅作补充**，不能替代站内购买信号 |

**刚需标品以站内信号为主；视觉驱动型品类可把社媒热度当补充，但别把主次颠倒。**

## 二、双模式对照表

本 skill 支持两种数据获取模式，**共用同一套判读规则**（`references/scoring.md`、
`references/hard-filters.md`）。切换模式只影响数据精度，不影响结论口径。

| 数据需求 | 官方路径 | MCP 路径 | 手动路径 | 缺失时降级 |
|---|---|---|---|---|
| 类目月销规模 | 商机探测器 | Sorftime `category_report` | 卖家精灵导出后交给 AI | 标"未筛"，不推进 |
| 关键词搜索量 | ABA / 商机探测器 | Sorftime `keyword_detail` | 卖家精灵关键词反查 | 用 Google Trends 定方向，标为估算 |
| 竞品评论原文 | 亚马逊前台 | Sorftime `product_reviews` | Helium 10 导出 CSV | 缩小样本，声明样本量 |
| 履约成本 | Revenue Calculator | 无官方 API | 官方计算器逐个填写 | **必填，不可降级** |
| 1688 货源 | — | Sorftime `ali1688_similar_product` | 人工 1688 搜图 | 标"未核" |
| BSR / 榜单 | 亚马逊前台 | Keepa MCP | 前台逐个记录 | 标"未核" |
| 站外趋势 | — | — | Google Trends 手工查 | 标为辅助信号 |

### 2.1 降级原则

**降级只能降"精度"，不能把"没查"变成"通过"。**

- 第三方估算可以替代官方数据做**排序**，但不能替代官方数据下**结论**。
- 任何降级必须在机会卡的 `evidence[].source` 里写明实际来源，
  并在 `gaps` 里记录"该项为估算/未核"。

## 三、各模式的配置要点

### 3.1 MCP 模式

- MCP 的价值：把 AI 与选品工具的查询接口连起来，**解决大模型编造市场数据的幻觉问题**。
- 需要自行开通对应工具 API 权限，**不存在开箱即用的全自动选品服务**。
- 配置示例（以 Sorftime 为例）：

```json
{
  "mcpServers": {
    "sorftime": {
      "url": "https://mcp.sorftime.com?key=YOUR_KEY"
    }
  }
}
```

- 配置完成后：**先列可用工具、做一次小范围查询确认调用成功，再开始批量分析。**
  直接上批量查询，失败时会浪费大量时间。

### 3.2 手动模式

- 适用：没有 MCP，或不想配 API Key。
- 工作流：在网页工具里导出 CSV / 截图 → 交给 AI 分析 → AI 按同一套规则判读。
- **手动模式不降低结论标准**：`references/hard-filters.md` 和
  `references/scoring.md` 的规则一字不变地适用。
- 这是对"两模式共用一套规则"的硬检验：同一批候选，
  有 MCP 和无 MCP 跑出来的**判读结论必须一致**，只是数据精度可能不同。

## 四、数据口径铁律

1. 所有数字标注来源与统计周期（如"2026-09 美国站月搜"）。
2. 区分官方数据与第三方估算，估算值必须给出估算方法。
3. **不把相近关键词的搜索量简单相加**当作市场总需求。
4. 历史数据不足 12 个月时，明确标注实际覆盖区间。
5. 低评分高销量样本需排查品牌背景、促销力度、变体结构，
   不能直接推出"新品容易做"。

## 五、合规与知识产权查询渠道

| 查询对象 | 官方渠道 |
|---|---|
| 商标 | USPTO Trademark Search |
| 发明/外观专利 | USPTO Patent Center、Google Patents |
| 类目准入/认证 | 亚马逊类目审批页；FCC / FDA / CPC / UL / Prop 65 各认证机构 |
| 品牌壁垒参考 | 亚马逊品牌注册库（**不能替代**官方商标专利检索） |
